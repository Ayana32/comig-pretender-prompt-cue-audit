# Results files

`COMIG_blind_justification_coding.xlsx` is the canonical reader-facing workbook. It contains five sheets: `Justification Coding`, `Cue Events`, `Codebook`, `Unblinding Key`, and `Results Summary`.

The `csv/` directory provides machine-readable copies:

- `justification_coding.csv`: one row per Judge justification;
- `cue_events.csv`: one row per completed cue event;
- `unblinding_key.csv`: design and response-identity metadata for each blind ID; and
- `results_summary_cells.csv`: a flat export of the formatted summary sheet.

`reproduced_metrics.json` is generated by `scripts/reproduce_statistics.py` from the first three CSV files. The workbook remains canonical for presentation; the CSV files are canonical for programmatic checking.
